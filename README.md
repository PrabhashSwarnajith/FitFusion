# **FitFusion - Social Media & Fitness App**

FitFusion is a fitness-focused social media app built with **Spring Boot** (backend) and **React** (frontend). It allows users to track workouts, share progress, and interact with the community. The app uses **Google OAuth2** for authentication and **Firebase** for real-time data and notifications.

## **Features:**
- Google OAuth2 login
- Track and share workouts
- Real-time notifications via Firebase
- Mobile-responsive design

## **Tech Stack:**
- **Backend**: Spring Boot, Google OAuth2, Firebase
- **Frontend**: React, React Router, Axios
- **Database**: Firebase Realtime Database/Firestore
