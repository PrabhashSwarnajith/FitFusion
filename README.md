# **FitFusion - Social Media & Fitness App**

FitFusion is a fitness-focused social media app built with Spring Boot (backend) and React (frontend). Users can track workouts, share progress, interact with the community, follow other users, and like posts. The app uses Google OAuth2 for authentication and MongoDB for storing user and workout data.

## **Features:**
- Google OAuth2 login
- Track and share workouts
- Follow and unfollow users
- Like and unlike posts

## **Tech Stack:**
- **Backend**: Spring Boot, Google OAuth2, Firebase, MongoDB
- **Frontend**: React, React Router, Axios
- **Database**: MongoDB (via Spring Data MongoDB)
